# ssc_python

# Analytics with Python 📊

A foundational data analytics repository showcasing **Exploratory Data Analysis (EDA)**, **mathematical algorithms**, and **decoupled business logic engines** using clean, production-ready functional Python programming.

---

## 🚀 Core Features

The project is structured into five distinct, decoupled blocks:

*   **Exploratory Data Analysis (EDA):** Tabular data ingestion, structural inspection, conditional subsection evaluations, and aggregate statistics using **Pandas** and **NumPy**.
*   **Mathematical Approximations:** Raw, optimized infinite-series mathematical loops computing arbitrary precision constants (e.g., Leibniz formula for π convergence) without heavy external math wrappers.
*   **Parametric Payroll Engine:** Decoupled functional logic engines computing post-tax net income streams with integrated safety fallbacks and currency structures.
*   **Conditional Real Estate Valuation Models:** Nested categorical cost-matrix architectures executing multi-parametric asset optimization calculations.
*   **Algorithmic List Comprehensions:** Memory-efficient parsing expressions measuring historical customer metrics, satisfaction ratings, and multi-year compound target growth trajectories.

---

## 🛠️ Tech Stack & Dependencies

*   **Language:** Python 3.12+
*   **Libraries:** 
    *   [Pandas](https://pandas.pydata.org/) — Structural data tracking & aggregations
    *   [NumPy](https://numpy.org/) — Precision benchmarking & vector math

## 📦 Getting Started

### 1. Clone the Repository
```bash
git clone https://github.com/your-username/analytics-with-python.git
cd analytics-with-python
```

### 2. Set Up a Virtual Environment (Recommended)
```bash
python -m venv venv
source venv/bin/activate  # On Windows use: venv\Scripts\activate
```

### 3. Install Dependencies
```bash
pip install pandas numpy notebook
```

### 4. Project File Structure
Ensure your dataset paths are aligned prior to execution:
```text
├── Data_101/
│   └── train.csv          # Titanic dataset used for EDA section
├── ssc_python.ipynb  # The core analytics codebase
└── README.md
```

## 🖥️ Usage

You can interact with the scripts in two ways:

### Via Jupyter Notebooks (Interactive)
Launch the workspace interface and open the target file:
```bash
jupyter notebook
```

### Via Terminal Output
If you convert or run it directly as a pure Python script:
```bash
jupyter nbconvert --to script ssc_paython.ipynb
```
